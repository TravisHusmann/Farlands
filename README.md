# Farlands

Windows builds of Farlands.

## Download

Get the newest build from [Releases](https://github.com/TravisHusmann/Farlands-releases/releases/latest): download the zip, unzip it anywhere, and run `Farlands.exe`.

## Updating

Download the new zip and replace the old folder. Your characters and worlds are kept in your own user folder, not the game's, so updating never touches them.
